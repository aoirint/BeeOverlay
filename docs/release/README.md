# Release Assets

This directory contains release-facing diagram and icon sources, retained
image derivatives, screenshots, and asset-specific authoring procedures. It
does not own the game-mechanics facts shown by the diagram; those remain in
`../domain/`.

- [Bee AI Break diagram authoring](bee-ai-break-diagram-authoring.md) covers the
  conditions diagram embedded in the root and package READMEs.
- [Icon authoring](icon-authoring.md) covers the editable icon source and
  regeneration of the package PNG.
- `screenshots/` contains the user-facing captures embedded in the root and
  package READMEs. They have no repeatable capture procedure yet.

See [visual asset rendering](../operations/visual-asset-rendering.md) for the
shared renderer and consumer-validation rules.
